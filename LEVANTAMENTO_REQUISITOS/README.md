# 📚 Curso: Levantamento de Requisitos

## 📌 Conteúdo Programático Geral
* Fundamentos do Levantamento de Requisitos.
* Processo de elicitação e análise.
* Especificação e documentação de sistemas.
* Validação e gerenciamento de escopo.

---

## 🔍 Requisitos Funcionais vs. Não Funcionais

### Requisitos Funcionais (RF)
* Definem o que o sistema deve fazer.
* Representam as funcionalidades diretas e recursos.
* **Exemplo:** O sistema deve emitir nota fiscal eletrônica.
* **Exemplo:** O usuário deve conseguir redefinir a senha por e-mail.

### Requisitos Não Funcionais (RNF)
* Definem como o sistema deve funcionar.
* Restrições de qualidade, desempenho, segurança e usabilidade.
* **Exemplo:** O sistema deve processar pagamentos em menos de 2 segundos.
* **Exemplo:** A interface deve ser responsiva para dispositivos móveis.

---

## 🧠 Técnicas de Elicitação de Requisitos

### 1. Brainstorming
* Sessões criativas em grupo para geração de ideias.
* Foco em quantidade de sugestões, sem julgamentos iniciais.
* Ideal para a fase de descoberta do projeto.
* Permite identificar visões diferentes sobre o mesmo problema.

### 2. Entrevistas
* Conversas diretas com stakeholders e usuários do sistema.
* **Estruturadas:** Roteiro fixo de perguntas fechadas.
* **Não estruturadas:** Conversa livre e exploratória.
* **Mistas:** Roteiro base com abertura para novos tópicos.

---

## 📐 Modelagem e Diagramas
* **Diagrama de Casos de Uso (UML):** Mostra os atores e suas interações com o sistema.
* **Diagrama de Classes:** Representa a estrutura de dados e regras de negócio.
* **Diagrama de Atividades:** Ilustra o fluxo de trabalho passo a passo do processo.
* **Diagrama de Sequência:** Evidencia a troca de mensagens entre objetos ao longo do tempo.

---

## 🎨 Prototipagem
* Criação de modelos visuais antes do desenvolvimento de código.
* **Baixa fidelidade:** Desenhos em papel (wireframes) para validar fluxos rápidos.
* **Alta fidelidade:** Telas interativas (Figma/Adobe XD) simulam a experiência real.
* **Objetivo:** Coletar feedback antecipado e reduzir custos de retrabalho.

---

## 📄 Relatórios Técnicos e Documentação
* **Documento de Especificação de Requisitos (SRS):** Registro oficial do escopo.
* **Matriz de Rastreabilidade:** Vincula os requisitos aos testes e códigos gerados.
* **Critérios de Aceite:** Regras claras que definem quando um requisito está pronto.
* **Ata de Reunião:** Registro de decisões tomadas com os clientes.
